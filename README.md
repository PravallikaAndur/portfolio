**Personal Portfolio Website**

This is my personal portfolio website built using **HTML, CSS, JavaScript**, and **Node.js**.
It showcases my **education, skills, and projects**, and includes direct links to my **email, LinkedIn, Instagram, and GitHub** profiles.

✨ Features

* 🎨 Modern responsive design 
* 📚 Education section (Graduation, Intermediate, School)
* ⚡ Skills section divided into Frontend, Backend, and Tools
* 📂 Projects displayed with cards (each card supports an image and GitHub link)
*  📞 Contact Me section with direct links to my profiles

🛠️ Technologies Used

* **Frontend**: HTML, CSS, JavaScript
* **Backend**: Node.js + Express.js
* **Version Control**: Git & GitHub
